# Temporal Graph Learning for Cyber Attack-Path Forecasting and Adaptive Defense

**Lateralis** (from *lateral movement*): forecasts an attacker's next hop through a network and recommends how to cut it off.

AI & ML course project (IS353IA, Lab Part B), 2026–27, by Krrish Agarwal.

The system treats a company network as a graph that changes over time (users and machines are
nodes, logins and connections are edges). A temporal graph neural network learns from past
activity to predict an attacker's next hop. The system then ranks the most likely attack paths
to critical assets and recommends a defensive action, such as isolating a machine or removing a
privilege.

See [ROADMAP.md](ROADMAP.md) for the full build plan, and [docs/research/](docs/research/README.md)
for the research on turning Lateralis into a self-hosted platform with LLM agents, evaluated on
real data (datasets, baselines, open-source stack, agents, evaluation, competitors).

## Setup
```bash
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -e ".[dev,ml,app]"
```

## Run the whole pipeline
```bash
.venv/bin/python -m attackpath.data.synthetic --n-graphs 300   # 1. fake networks with labeled attacks
.venv/bin/python -m attackpath.graph.builder                   # 2. hourly graph snapshots
.venv/bin/python -m attackpath.models.train                    # 3. train + calibrate the temporal GNN
.venv/bin/python -m attackpath.eval.evaluate                   # 4. test-set metrics vs baselines
.venv/bin/python -m attackpath.api.server                     # 5. web app at http://127.0.0.1:8000
.venv/bin/python -m pytest -q                                  # tests
```
**Presentation demo (no install):** open [demo/lateralis.html](demo/lateralis.html) in a browser; the
presenter script and controls are in [demo/PRESENTATION.md](demo/PRESENTATION.md).

See [DEMO.md](DEMO.md) for a walkthrough script and **[docs/Lateralis_Manual.pdf](docs/Lateralis_Manual.pdf)** for the full user manual, tech stack, dataset and next steps. The exported dataset is in [dataset/](dataset/).

## Datasets
- [LANL 2015 Comprehensive, Multi-Source Cyber-Security Events](https://csr.lanl.gov/data/cyber1/) (primary, real enterprise data, CC0)
- [DARPA OpTC](https://github.com/FiveDirections/OpTC-data) (secondary, cross-environment check)
- Telemetry from the project's Docker attack lab (emulated multi-hop attacks, planned)
- Synthetic attack graphs generated by this repo (smoke tests)

Why these and not CICIDS2017 or UNSW-NB15: see [the research report](docs/research/reports/Lateralis%20platform%20research.md).
Data files are not committed. The synthetic data currently goes in `data/` (git-ignored); real
datasets will live in `C:\lateralis-data`, outside the repo (see [ROADMAP.md](ROADMAP.md), Phase 1).
