# Temporal Graph Learning for Cyber Attack-Path Forecasting and Adaptive Defense

AI & ML course project (IS353IA, Lab Part B), 2026–27, by Krrish Agarwal.

The system treats a company network as a graph that changes over time (users and machines are
nodes, logins and connections are edges). A temporal graph neural network learns from past
activity to predict an attacker's next hop. The system then ranks the most likely attack paths
to critical assets and recommends a defensive action, such as isolating a machine or removing a
privilege.

See [ROADMAP.md](ROADMAP.md) for the full build plan.

## Setup
```bash
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -e ".[dev,ml]"
```

## Quick start
```bash
# 1. generate synthetic networks with labeled attack paths
.venv/bin/python -m attackpath.data.synthetic --n-graphs 300

# 2. turn events into hourly graph snapshots
.venv/bin/python -m attackpath.graph.builder

# 3. run tests
.venv/bin/python -m pytest -q
```

## Datasets
- Synthetic attack graphs (generated by this repo)
- [LANL cyber-security events](https://csr.lanl.gov/data/cyber1/)
- [CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html)
- [UNSW-NB15](https://research.unsw.edu.au/projects/unsw-nb15-dataset)

Data files are not committed. They go in `data/` (git-ignored).
